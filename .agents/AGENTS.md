# Workspace Rules for EcoTrash-AR

## Automatically Push Changes to GitHub
Every time you make any modifications, upgrades, or fixes to the project files, you MUST:
1. Clone the remote repository: `https://github.com/pitchayadanava-beep/EcoTrash-AR.git`
2. Copy all updated project files into the cloned folder.
3. Commit with a meaningful, conventional commit message (e.g. `feat: ...`, `fix: ...`, `revert: ...`).
4. Push the changes to the remote `main` branch.
5. Report the successful sync and push to the user with the repository URL link.
